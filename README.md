### Minsu Kwak

Graduate researcher in particle physics, Chung-Ang University.

I reconstruct neutrino events for the [IceCube Neutrino Observatory](https://icecube.wisc.edu/) and its Upgrade,
and simulate and reconstruct events in CANDY, a liquid-scintillator detector read out by SiPMs inside the liquid.

**IceCube**
- Maximum-likelihood cascade reconstruction of GeV neutrinos (Millipede / Monopod)
- Per-PMT photon tables for the Upgrade multi-PMT modules (mDOM, D-Egg)

**CANDY**
- Geant4 simulation of the detector, validated against measured photon counts
- Neural-network reconstruction of muon tracks and event vertices
- Reactor sterile-neutrino sensitivity
- Paper: [Charged-particle topology reconstruction with an in-liquid SiPM array](https://arxiv.org/abs/2609.25532)

C++ · Python · Geant4 · ROOT · IceTray · PyTorch · HTCondor
